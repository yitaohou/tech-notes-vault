# Query Rewriting

%% ytkb:def %%
也称 query reformulation、normalization 或 expansion，指补全查询中缺失上下文信息以提升检索效果的技术。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-rag]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- query rewriting 通过把用户查询中缺失的上下文补全来提高检索效果，例如用户先问「Paris」后又问「它的人口是多少」，系统会把查询改写为「巴黎的人口是多少」。（[33:02](https://youtu.be/JV3pL1_mn2M?t=1982)）

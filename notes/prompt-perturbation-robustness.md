# Prompt Perturbation Robustness

%% ytkb:def %%
模型对提示词微小改动（如数字用阿拉伯数字还是英文单词表示）不敏感的程度，反映其鲁棒性。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-prompt-engineering]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 模型对 prompt 措辞微小变化（如用数字5还是英文单词FIVE）的敏感程度体现其鲁棒性，鲁棒性越强的模型通常整体能力也越强，所需的 prompt engineering 工作量也越少。（[24:02](https://youtu.be/JV3pL1_mn2M?t=1442)）

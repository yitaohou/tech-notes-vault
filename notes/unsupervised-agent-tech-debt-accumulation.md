# Unsupervised Agent Tech Debt Accumulation

%% ytkb:def %%
指长期让 AI agent 无监督工作、且不检查生成代码质量或做相应优化，会使应用表面功能正常，实则底层积累大量技术债，一旦要改动某个模块就会牵连整体崩溃。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-coding-agents]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:hA_XnzB1Ef8 %%
### 来自 [[2026-07-07-3-frontend-skills-ai-cant-replace-become-ai-proof]]
- 让 agent 无人监督地工作而不审查代码质量，应用可能看起来实现了预期功能，但实际上是坐在一堆技术债之上，一旦想挪动某个小部件，整个结构就会一起崩塌。（[09:03](https://youtu.be/hA_XnzB1Ef8?t=543)）

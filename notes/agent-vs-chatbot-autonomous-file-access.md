# Agent vs Chatbot Autonomous File Access

%% ytkb:def %%
agent 与聊天框（chatbot）的关键区别之一：聊天框的输入完全由用户主动提供、内容可控，而 agent 会自主决定读取哪些文件、上传哪些内容，用户难以直接控制。

## 要点

%% ytkb:video:WrwA7FYGPdQ %%
### 来自 [[2026-09-02-deepseek-harness-开源-11-天爆-5-个漏洞ai-读网页电脑被控有人-api-额度]]
- 相比聊天框「你发什么就是什么」的可控输入方式，agent 会自主决定去读取什么文件、上传什么文件，这使得数据泄露风险比普通 chatbot 更难预判和控制。（[03:00](https://youtu.be/WrwA7FYGPdQ?t=180)）

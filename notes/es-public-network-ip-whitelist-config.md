# ES Public Network Access IP Whitelist Configuration

%% ytkb:def %%
在腾讯云 ES 集群的可视化访问控制中，可以修改公网访问策略，将 IP 白名单设置为允许所有 IP 地址访问，从而放开外部访问权限。

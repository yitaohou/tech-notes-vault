# Intent Debt

%% ytkb:def %%
指 Agent 每次开启新会话都从零开始，若用户没有把要求说清楚，Agent 就会用自己的猜测填补空白，而这些猜测往往和项目实际要求存在偏差，由此产生的隐性成本。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-prompt-engineering]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:KgiwIEBeOHw %%
### 来自 [[2026-06-16-什么是循环工程loop-engineering-coding-agent-子agent-mcp协议]]
- Skill 通过把项目的规则、约定、构建步骤甚至过往踩过的坑正式记录下来，使 Agent 每次运行都能读取这些知识，从而避免 intent debt 的重复消耗，并让知识积累产生复利效应。（[09:03](https://youtu.be/KgiwIEBeOHw?t=543)）

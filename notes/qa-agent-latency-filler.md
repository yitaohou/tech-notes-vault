# Q&A Agent as Latency Filler

%% ytkb:def %%
指在 router agent 完成意图判断和路由决策期间，用自然语言过渡性回应（如展示 thinking process）来维持对话流畅感、争取处理时间的 agent。
%% ytkb:end %%

## 要点

%% ytkb:video:CyLYY_xb5bQ %%
### 来自 [[2025-08-25-you-can-learn-ai-agent-system-design-in-19-min-rag]]
- Q&A agent 会在 router agent 思考路由决策的同时，用「让我帮你查一下」之类的话术并展示 thinking process 来回应用户，使对话显得自然流畅，同时为后端处理争取时间。（[06:00](https://youtu.be/CyLYY_xb5bQ?t=360)）

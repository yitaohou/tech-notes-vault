# Passive vs Contest Usage Pattern

%% ytkb:def %%
LeetCode 类平台存在两种使用模式：平时用户随时随地浏览、稍后再提交（无时间限制的被动使用），比赛期间用户集中在同一时间段访问同一批题目。
%% ytkb:end %%

## 要点

%% ytkb:video:QBHTbtWSECg %%
### 来自 [[2026-03-15-system-design-mock-interview-design-leetcode-ft-ex]]
- 平时的被动使用没有时间约束，用户可以随时查看题目、之后再提交；而比赛期间用户会集中访问同一组题目。（[09:03](https://youtu.be/QBHTbtWSECg?t=543)）

# Attention Mechanism

%% ytkb:def %%
Transformer 引入的机制，允许模型在生成每个输出 token 时对输入序列中不同 token 的重要性进行加权参考。
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- attention 机制让模型在生成每个输出 token 时可以参考输入的任意位置，相当于回答问题时可以随时翻阅书中任意一页，而不只是依赖摘要。（[03:00](https://youtu.be/JV3pL1_mn2M?t=180)）

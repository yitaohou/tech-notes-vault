# Memory Tier Routing OS Analogy

%% ytkb:def %%
用操作系统自动决定文件存内存还是硬盘作类比，说明持续学习中信息该分配到哪个层级应是可被自动解决的科学问题，而非依赖人工判断。
%% ytkb:end %%

## 要点

%% ytkb:video:zyzeyxuG42Q %%
### 来自 [[2026-08-19-下一代大模型持续学习]]
- 团队用「存文件时不需手动决定放内存还是硬盘、操作系统会自动处理」来类比：大模型持续学习中信息该进模型权重、记忆还是工具层，理想情况下也应由系统自动判断，这是一个可研究解决的科学问题，不应靠人类拍脑袋决定。（[03:00](https://youtu.be/zyzeyxuG42Q?t=180)）

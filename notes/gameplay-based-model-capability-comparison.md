# Gameplay-Based Model Capability Comparison

## 要点

%% ytkb:video:buYQ-_V2Wv0 %%
### 来自 [[2026-09-04-一个视频搞懂deepseek-harness]]
- 作者让V4 Flash、V4 Pro与GLM5.3 Flash分别玩同一款连线游戏，发现V4 Flash和V4 Pro眼睁睁看着对手连成三四子也不会主动防守或反击，而GLM5.3 Flash能有来有回、甚至布出双重杀阵直接获胜，体现出模型能力的明显差距。（[06:02](https://youtu.be/buYQ-_V2Wv0?t=362)）

# Orca CLI-GUI Hybrid Positioning

%% ytkb:def %%
Orca 的定位优势在于让用户既能使用终端命令行版本的 Agent（如 Codex），又能体验元素选择器、diff 查看等可视化功能，是二者结合的解决方案。
%% ytkb:end %%

所属: [[ai-coding-agents]] · [[ai]]

## 要点

%% ytkb:video:U6ZHJPNvlxU %%
### 来自 [[2026-09-14-介绍-herdr-后评论区为什么都在推荐-orca]]
- 元素抓取这类可视化功能在 Codex 等命令行版 Agent 软件中已有内置，但如果既想用命令行版 Agent、又想体验可视化功能，Orca 可以把两者结合在一起使用。（[03:00](https://youtu.be/U6ZHJPNvlxU?t=180)）

# Agent Efficiency Metrics

%% ytkb:def %%
用于衡量 agent 执行效率的一组量化指标，包括步骤数、成本、耗时及与基线的对比。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-evaluation]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 评估 agent 效率的指标包括完成任务平均所需步骤数、完成任务的成本、每个动作的平均耗时、是否存在特别慢或昂贵的动作，以及与基线（如另一个 agent 或人类）的对比表现。（[39:04](https://youtu.be/JV3pL1_mn2M?t=2344)）

# DSH EGO Browser Plugin

%% ytkb:def %%
一款为 DeepSeek Harness 提供的插件，让智能体能够模拟人类手动操作浏览器来读取网页信息，可缓解触发网站反爬虫机制的问题。
%% ytkb:end %%

## 要点

%% ytkb:video:buYQ-_V2Wv0 %%
### 来自 [[2026-09-04-一个视频搞懂deepseek-harness]]
- 安装 DSH-EGO Browser 插件后，智能体能够以模拟人类手动操作浏览器的方式读取所需网页信息，用于应对经常触发网站反爬虫机制的问题，且其具体操作执行过程可以在侧栏中直接观察到。（[03:01](https://youtu.be/buYQ-_V2Wv0?t=181)）

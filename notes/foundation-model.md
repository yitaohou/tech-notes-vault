## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- Foundation model 的知识边界完全取决于训练数据：如果训练阶段没有见过某种语言或概念，模型就不具备相应知识。（[00:00](https://youtu.be/JV3pL1_mn2M?t=0)）
- Foundation model 目前已广泛应用于 GitHub Copilot 等 coding assistant、图像生成工具、写作辅助、客服机器人和复杂数据分析系统等场景。（[00:00](https://youtu.be/JV3pL1_mn2M?t=0)）

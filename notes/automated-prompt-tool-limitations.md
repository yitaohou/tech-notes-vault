# Limitations of Automated Prompt Tools

%% ytkb:def %%
自动化提示词工具存在的局限性：调用成本高、可能产出有瑕疵的提示词、难以跟上模型更新速度。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-prompt-engineering]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 自动化提示词工具如果底层要发起大量 API 调用会很贵，还可能生成带 typo 或其他问题的提示词，并且未必能跟上模型需求的变化，因此建议先做 manual prompt engineering，再考虑引入自动化工具。（[27:02](https://youtu.be/JV3pL1_mn2M?t=1622)）

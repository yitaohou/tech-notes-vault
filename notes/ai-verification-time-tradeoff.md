# AI Coding Verification Time Tradeoff

%% ytkb:def %%
指 coding agent 虽然能把代码实现时间降到接近零，但会相应增加人工验证代码正确性所需的时间这一权衡现象。
%% ytkb:end %%

## 要点

%% ytkb:video:KuClyhvSzXk %%
### 来自 [[2026-06-18-frontend-system-design-explained-w-senior-engineer]]
- Claude Code 等 coding agent 能把功能实现时间降到几乎为零，但会显著增加验证时间，因此 AI 时代前端系统设计的目标转变为降低验证时间、减少架构漂移，同时最大化开发速度，而不是单纯追求实现速度。（[00:00](https://youtu.be/KuClyhvSzXk?t=0)）

# UI Consistency Reduces Cognitive Load

%% ytkb:def %%
指用户在浏览一致性强的界面时，大脑只需要关注真正发生变化的内容，从而降低认知负荷的用户体验原则。
%% ytkb:end %%

## 要点

%% ytkb:video:hA_XnzB1Ef8 %%
### 来自 [[2026-07-07-3-frontend-skills-ai-cant-replace-become-ai-proof]]
- 保持 UI 一致性的意义在于，当用户看到一致的界面时大脑处理负担更小，只有真正变化的部分才需要被注意，这也是使用统一样式规范的核心原因。（[06:02](https://youtu.be/hA_XnzB1Ef8?t=362)）

# Minimal vs Full-Featured Tool Tradeoff

%% ytkb:def %%

## 要点

%% ytkb:video:j0Z5cngKDeo %%
### 来自 [[2026-07-27-我为什么对-pi-agent-产生了兴趣]]
- 作者类比十几年前偏爱 Drupal、WordPress 这类精简 CMS、嫌弃 DedeCMS 等国内臃肿系统的经历，指出内核精简虽讨喜，但大而全、开箱即用对大多数用户其实更有优势，因此仅凭「小而干净」并不足以打动他去尝试 Pi Agent。（[00:00](https://youtu.be/j0Z5cngKDeo?t=0)）

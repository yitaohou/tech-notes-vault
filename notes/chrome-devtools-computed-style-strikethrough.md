# Chrome DevTools Computed Style Strikethrough

%% ytkb:def %%
Chrome DevTools 中被 specificity 更高的规则覆盖的 CSS 声明会以删除线形式显示在元素样式面板中。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[frontend-css-styling]] · [[frontend]]
%% ytkb:end %%

## 要点

%% ytkb:video:AMerB8XjfZ0 %%
### 来自 [[2026-06-30-top-15-frontend-interview-questions-for-2026-wa-se]]
- 在 Chrome DevTools 的元素样式面板里，被覆盖的 CSS 属性（如 background-color white）会显示为带删除线的文本，鼠标悬停在选择器上还能看到其 specificity 数值。（[27:07](https://youtu.be/AMerB8XjfZ0?t=1627)）

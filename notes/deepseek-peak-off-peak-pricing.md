# DeepSeek Peak/Off-Peak API Pricing

%% ytkb:def %%
DeepSeek 在工作日实行的按时段浮动计价机制，高峰时段的 API 调用价格明显高于非高峰时段。
%% ytkb:end %%

## 要点

%% ytkb:video:buYQ-_V2Wv0 %%
### 来自 [[2026-09-04-一个视频搞懂deepseek-harness]]

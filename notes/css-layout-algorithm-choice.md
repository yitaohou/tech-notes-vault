# CSS Layout Algorithm Choice for Responsiveness

%% ytkb:def %%
响应式设计第二原则：根据布局复杂度选择合适的 CSS 布局算法，flex 和 block 相对易用，grid 更强大但学习门槛更高。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[frontend-css-styling]] · [[frontend]]
%% ytkb:end %%

## 要点

%% ytkb:video:AMerB8XjfZ0 %%
### 来自 [[2026-06-30-top-15-frontend-interview-questions-for-2026-wa-se]]
- flex 通常是实现响应式布局最简单的方式，block（浏览器默认布局，段落纵向排列、单词横向排列）也适合非常简单的布局；grid 适合复杂布局，但只有在熟练掌握 grid 或大量配合媒体查询时才能用好。（[27:07](https://youtu.be/AMerB8XjfZ0?t=1627)）

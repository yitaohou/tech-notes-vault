# Manual Code Review of AI-Generated Output

%% ytkb:def %%
工程师必须亲自查看 AI 生成的 pull request 代码进行真正的 code review，而非依赖 AI 自身做的代码检查，才能确认代码质量是否过关。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-coding-agents]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:hA_XnzB1Ef8 %%
### 来自 [[2026-07-07-3-frontend-skills-ai-cant-replace-become-ai-proof]]
- 使用 agent 生成代码后，工程师需要打开对应 pull request 亲自做 code review（而非让 AI 做 code review），这被类比为工厂大量产出蛋糕后，你必须亲口尝一尝才能知道好不好吃。（[12:03](https://youtu.be/hA_XnzB1Ef8?t=723)）

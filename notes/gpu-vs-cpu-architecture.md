# GPU vs CPU Architecture

%% ytkb:def %%
CPU 与 GPU 在核心数量和设计目标上的架构差异，决定了二者分别适用于不同的计算场景。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-engineering-fundamentals]] · [[ai]]

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- CPU 通常只有少量（高端机型最多约 64 个）强大核心，为通用计算优化；GPU 则拥有数千个更小的核心，专为并行处理优化，因此更适合处理主导 ML 工作负载的矩阵乘法运算。（[63:05](https://youtu.be/JV3pL1_mn2M?t=3785)）

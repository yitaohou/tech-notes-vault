# DSH Sub-Agent Codex Plugin

%% ytkb:def %%
一类为 DeepSeek Harness 提供的插件，可让已订阅 Codex 或 Claude Code 的用户将其接入作为子智能体使用。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-agent-architecture]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:buYQ-_V2Wv0 %%
### 来自 [[2026-09-04-一个视频搞懂deepseek-harness]]
- 如果用户已有 Codex 或 Claude Code 的订阅，可安装 DSH Sub-Agent Codex 这类插件，让 DeepSeek 负责制定计划、再调用 Codex 作为子智能体去执行具体任务，因为执行是否到位比负责规划的模型是否聪明更重要。（[03:01](https://youtu.be/buYQ-_V2Wv0?t=181)）

# Claude Code System Prompt Reduction

%% ytkb:def %%

## 要点

%% ytkb:video:Lle_EJljIoo %%
### 来自 [[2026-07-26-删掉80提示词后claude-5反而变强了anthropic官方的做减法哲学]]
- Anthropic 工程师 Thariq Shihipar 透露，针对 Opus 5 和 Sonnet 5 两个新模型，Claude Code 的系统提示词被缩短了超过 80%。（[00:00](https://youtu.be/Lle_EJljIoo?t=0)）
- 此次 Claude Code 系统提示词精简删除的是大量示例、重复指令和过度绝对的限制，而不是把安全规则删掉。（[00:00](https://youtu.be/Lle_EJljIoo?t=0)）
- Anthropic 内部编码评估显示，Claude Code 系统提示词大幅精简后没有测出明显的性能下降。（[00:00](https://youtu.be/Lle_EJljIoo?t=0)）

# Multi-Agent vs Human Cost-Quality Tradeoff

%% ytkb:def %%
指用多智能体系统完成大型开发任务，相较雇佣人类专家开发者，存在速度快、成本低但最终质量可能较低的权衡关系。

## 要点

%% ytkb:video:Mi5wOpAgixw %%
### 来自 [[2026-02-22-multi-agent-systems-explained-in-17-minutes]]
- 若改由人类开发者构建这个 C compiler，可能需要数月而非两周，成本可能高达约 10 万美元而非 2 万美元，但最终质量很可能高于多智能体系统产出的结果。（[09:02](https://youtu.be/Mi5wOpAgixw?t=542)）
- 多智能体开发存在质量与速度/成本之间的自然权衡：想要更快更便宜可以牺牲质量，想要最高质量则需要让人类耗费更长时间，并支付比 API 调用更高的费用。（[09:02](https://youtu.be/Mi5wOpAgixw?t=542)）

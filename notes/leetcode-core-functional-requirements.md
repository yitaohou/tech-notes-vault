# LeetCode Core Functional Requirements

%% ytkb:def %%
LeetCode 平台的核心功能需求集合：浏览题目列表、查看题目详情并用任意语言编写解答、提交解答并获得即时反馈。

## 要点

%% ytkb:video:QBHTbtWSECg %%
### 来自 [[2026-03-15-system-design-mock-interview-design-leetcode-ft-ex]]
- LeetCode 系统设计的核心功能需求包括：（1）浏览可用编程题目列表；（2）查看具体题目并用任意语言编写代码解答；（3）提交解答后即时获得反馈，判断代码是否通过全部测试用例。（[00:01](https://youtu.be/QBHTbtWSECg?t=1)）

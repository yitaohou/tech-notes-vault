# Knowledge Augmentation Tools

%% ytkb:def %%
agent 工具的一大类，用于帮助 agent 获取外部知识，包括文本或图像检索器、SQL 执行器、网络搜索、访问库存系统的 API、邮件读取器和网页浏览器等。
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- Agent 工具中的第一大类是 knowledge augmentation tools，包括类似 RAG 中的文本或图像检索器、用于访问数据库的 SQL executor、网络搜索能力、访问库存系统等的 API、邮件读取器，以及用于浏览公开或私有网页内容的 web browser。（[36:03](https://youtu.be/JV3pL1_mn2M?t=2163)）
%% ytkb:end %%

%% ytkb:video:CyLYY_xb5bQ %%
### 来自 [[2025-08-25-you-can-learn-ai-agent-system-design-in-19-min-rag]]
- 通过集成 Shopify API，agent 可以查询订单当前状态以及退货授权（RMA）信息，必要时也可处理换货动作。（[09:01](https://youtu.be/CyLYY_xb5bQ?t=541)）
- 集成第三方物流（3PL）API 可让 agent 实时查询包裹当前物流位置，用于回答「我的订单在哪里」类客服问题。（[09:01](https://youtu.be/CyLYY_xb5bQ?t=541)）

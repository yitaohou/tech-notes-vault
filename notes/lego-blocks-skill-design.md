# LEGO Blocks Skill Design

%% ytkb:def %%
Matt Pocock 提出的 skill 设计理念：把 skill 做成可自由拼接的模块化积木，而非固定顺序的流水线，让使用者自主决定从哪一步开始、哪一步结束。

# HTTP Status Code Categories

%% ytkb:def %%
HTTP 状态码按数字区间划分为不同类别，用于表示请求处理结果的性质。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[backend-api-design]] · [[backend]]
%% ytkb:end %%

## 要点

%% ytkb:video:oYxTTirKY8M %%
### 来自 [[2026-05-26-system-design-explained-apis-databases-caching-cdn]]
- HTTP 状态码按区间分类：2xx 表示请求成功，3xx 表示重定向，4xx 表示客户端错误，5xx 表示服务器端错误。（[49:40](https://youtu.be/oYxTTirKY8M?t=2980)）
- RESTful API 的状态码按开头数字分类：2xx 表示成功，3xx 表示重定向，4xx 表示客户端错误，5xx 表示服务端错误。（[72:17](https://youtu.be/oYxTTirKY8M?t=4337)）

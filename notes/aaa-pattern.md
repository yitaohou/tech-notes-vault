# AAA Pattern (Arrange-Act-Assert)

%% ytkb:def %%
一种统一的测试结构范式，把任何测试拆分为 arrange（准备）、act（执行）、assert（断言）三个阶段。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[career-industry-engineering-practices]] · [[career-industry]]
%% ytkb:end %%

## 要点

%% ytkb:video:AMerB8XjfZ0 %%
### 来自 [[2026-06-30-top-15-frontend-interview-questions-for-2026-wa-se]]
- 无论测试或 UI 多复杂，都可以用 AAA pattern 拆分：arrange 阶段准备 mocks 和 test doubles，act 阶段触发/渲染组件或点击按钮，assert 阶段做断言，这样让 AI 写出的测试更易读。（[12:02](https://youtu.be/AMerB8XjfZ0?t=722)）

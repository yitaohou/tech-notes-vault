# Inference Throughput

%% ytkb:def %%
Throughput 指推理服务在所有请求上每秒能生成的输出 token 数，是衡量推理系统性能的核心指标之一。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-inference-optimization]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- Throughput 定义为一个推理服务在处理所有请求时每秒能生成的输出 token 数。（[63:05](https://youtu.be/JV3pL1_mn2M?t=3785)）
- 更高的 throughput 通常意味着更低的单位成本，这正是生产系统中重视 throughput 优化的原因。（[63:05](https://youtu.be/JV3pL1_mn2M?t=3785)）

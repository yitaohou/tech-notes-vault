# Start With Single-Agent System First

%% ytkb:def %%

%% ytkb:end %%

## 要点

%% ytkb:video:Mi5wOpAgixw %%
### 来自 [[2026-02-22-multi-agent-systems-explained-in-17-minutes]]
- 构建 agent 系统时通常应该先从单 agent 系统开始，借此评估该 agent 完成特定任务的能力，只有在满足特定判断标准之后，才有必要转向 multi-agent 系统。（[06:02](https://youtu.be/Mi5wOpAgixw?t=362)）

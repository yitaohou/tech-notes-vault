# MOD Search Plugin

%% ytkb:def %%
一款为 DeepSeek Harness 提供搜索能力扩展的插件，可让智能体接入国内外各种搜索引擎，扩大搜索覆盖范围。
%% ytkb:end %%

## 要点

%% ytkb:video:buYQ-_V2Wv0 %%
### 来自 [[2026-09-04-一个视频搞懂deepseek-harness]]
- 安装 MOD Search 插件可以让智能体接入国内外多种搜索引擎以获得更广的搜索范围；若使用的是非官方模型、原本缺失联网搜索能力，该插件还能直接补足这项功能。（[03:01](https://youtu.be/buYQ-_V2Wv0?t=181)）

# Clear and Explicit Instructions Strategy

%% ytkb:def %%
prompt engineering 的一项关键策略：把指令写得清晰明确以减少歧义。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-prompt-engineering]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 有效 prompt engineering 的第一个策略是写清晰明确的指令，例如让模型给作文打分时，需要说明具体评分标准、是否允许打小数分、无法判断时该如何处理等细节，以减少歧义。（[24:02](https://youtu.be/JV3pL1_mn2M?t=1442)）
%% ytkb:end %%

%% ytkb:video:CyLYY_xb5bQ %%
### 来自 [[2025-08-25-you-can-learn-ai-agent-system-design-in-19-min-rag]]
- 为 return planner agent 编写提示词时需要清楚定义执行顺序（先做各项 check，再触发功能调用）和参数类型，确保 agent 准确理解需要执行的步骤，避免过度简化导致理解偏差。（[13:45](https://youtu.be/CyLYY_xb5bQ?t=825)）

# Bootstrap Evaluation Reliability Test

%% ytkb:def %%

%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 可以对评估集做多个 bootstrap 抽样，若不同抽样结果差异很大（例如一次 90% 一次 70%），说明该评估流程不可信。（[21:01](https://youtu.be/JV3pL1_mn2M?t=1261)）

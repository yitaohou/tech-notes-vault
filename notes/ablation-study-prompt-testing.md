# Ablation Study for Prompt Testing

%% ytkb:def %%
一种拿掉某一条 Prompt/规则、其他条件保持不变，再比较结果变好、变差或无影响，以此判断该规则是否仍然必要的实验方法（消融实验）。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-evaluation]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:Z-4AsgTYv2c %%
### 来自 [[2026-09-02-claude-code-之父建議每六個月刪光你的-claudemd]]
- Boris 提到 Claude Code 团队用消融实验（ablation study）来判断某条 Prompt 规则是否还有必要：拿掉一个变因、保持其他条件不变，再比较结果是变好、变差还是没有影响。（[03:01](https://youtu.be/Z-4AsgTYv2c?t=181)）
- Claude Code 团队测试 Prompt 是否可删并非凭感觉随意删掉一次、觉得模型好像变聪明了就下结论，而是采用有系统的消融实验方法论。（[03:01](https://youtu.be/Z-4AsgTYv2c?t=181)）

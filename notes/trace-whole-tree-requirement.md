# Trace the Whole Tree Requirement

%% ytkb:def %%
Trajectory 提出的经验捕捉第一步：完整追踪 agent 整棵行为树（包括子 agent 调用、工具调用等），而非像多数公司那样只记录主流程后就丢弃其余部分。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-continual-learning]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:zyzeyxuG42Q %%
### 来自 [[2026-08-19-下一代大模型持续学习]]
- 捕捉经验的第一步是完整追踪 agent 的整棵行为树（trace the whole tree），而不是像大多数公司那样只记录主流程、把子 agent 调用和工具调用都扔掉。（[00:00](https://youtu.be/zyzeyxuG42Q?t=0)）

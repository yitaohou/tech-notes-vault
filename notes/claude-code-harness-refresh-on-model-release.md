# Claude Code Harness Refresh on Model Release

%% ytkb:def %%
Claude Code 团队每次有新模型推出时就对产品外层的 system prompt、tools、skills 做一次全面大扫除，检查并清除已不再需要的旧设定，而非把一套提示词永久沿用。

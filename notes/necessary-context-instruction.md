# Necessary Context Instruction Category

%% ytkb:def %%
instructions 三分类中的第一类，指模型不可能自己知道的背景信息，如品牌定位、目标受众、专案资料位置，这类设定必须保留。

%% ytkb:video:Z-4AsgTYv2c %%
### 来自 [[2026-09-02-claude-code-之父建議每六個月刪光你的-claudemd]]

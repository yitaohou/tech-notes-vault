# API Definition

%% ytkb:def %%
API（应用程序接口）是定义软件组件之间如何交互的契约，规定客户端可以发起哪些请求以及服务端会返回哪些响应。
%% ytkb:end %%

## 要点

%% ytkb:video:oYxTTirKY8M %%
### 来自 [[2026-05-26-system-design-explained-apis-databases-caching-cdn]]
- API 本质上是客户端（如浏览器、手机 App）与服务端之间的一份契约，定义了可用的 endpoint、可使用的方法，以及针对每个 endpoint 能期望得到的响应。（[30:03](https://youtu.be/oYxTTirKY8M?t=1803)）

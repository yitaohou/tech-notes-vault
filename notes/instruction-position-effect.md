# Instruction Position Effect

%% ytkb:def %%
模型通常在指令位于提示词开头或结尾时理解得更好，指令被埋在中间容易效果下降的现象。
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 模型通常在指令出现在 prompt 的开头或结尾时理解得更准确，如果指令被埋在中间部分，理解效果会下降。（[24:02](https://youtu.be/JV3pL1_mn2M?t=1442)）

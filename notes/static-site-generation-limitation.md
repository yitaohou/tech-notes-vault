# Static Site Generation Limitation

%% ytkb:def %%
指预渲染的静态站点方案只适合内容不经常变化的场景，若站点内容（如博客）需要频繁更新发布，该方案就不再适用。
%% ytkb:end %%

## 要点

%% ytkb:video:KuClyhvSzXk %%
### 来自 [[2026-06-18-frontend-system-design-explained-w-senior-engineer]]
- 静态站点预渲染方案仅适用于内容变化不频繁的场景，例如博客这类需要经常发布新内容的站点就不适合采用这种方式。（[30:07](https://youtu.be/KuClyhvSzXk?t=1807)）

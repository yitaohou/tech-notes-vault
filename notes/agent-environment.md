# Agent Environment

%% ytkb:def %%
agent 所处的环境由具体应用场景决定，例如游戏对弈 agent 的环境是游戏本身，网页抓取 agent 的环境是互联网。

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- Agent 的环境由具体使用场景定义：对于 game playing agent，游戏本身就是它的环境；对于 web scraping agent，互联网就是它的环境。（[36:03](https://youtu.be/JV3pL1_mn2M?t=2163)）

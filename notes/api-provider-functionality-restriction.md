# API Provider Functionality Restriction

%% ytkb:def %%
使用第三方模型 API 意味着被限制在该提供商所支持的功能范围内，例如可能无法进行 fine-tune 或获取 log probabilities。
%% ytkb:end %%

所属: [[ai-model-selection-deployment]] · [[ai]]

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 使用第三方 API 会把应用限制在该提供商所提供的功能范围内，例如可能无法 fine-tune 模型，也无法获取 log probabilities。（[18:01](https://youtu.be/JV3pL1_mn2M?t=1081)）

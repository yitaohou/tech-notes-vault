# Agent Compounding Error Risk

%% ytkb:def %%
agent 因需要执行多步骤才能完成任务，各步骤的失败概率会复合累加，导致整体成功率随步骤数增加而下降，且因其可操作强大工具而风险更高。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-agent-architecture]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 相比更简单的 AI 应用，agent 通常需要更强大的模型，因为完成任务往往需要多个步骤，每增加一步都会因为复合误差（compounding errors）而降低整体成功率，且由于 agent 能访问强大的工具，出错的风险和代价也更高。（[36:03](https://youtu.be/JV3pL1_mn2M?t=2163)）

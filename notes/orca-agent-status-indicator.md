# Orca Agent Status Indicator

%% ytkb:def %%
Orca 为每个 Agent/终端标签提供状态指示灯，用于显示该 Agent 当前是否正在运行，便于在查看其他标签时同步了解各 Agent 的工作状态。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-coding-agents]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:U6ZHJPNvlxU %%
### 来自 [[2026-09-14-介绍-herdr-后评论区为什么都在推荐-orca]]
- Orca 的每个标签旁会显示状态指示灯，当某个 Agent 正在运行时指示灯会发生变化，使用户即便切换到其他 Agent 标签，也能了解另一个 Agent 的运行状态。（[03:00](https://youtu.be/U6ZHJPNvlxU?t=180)）

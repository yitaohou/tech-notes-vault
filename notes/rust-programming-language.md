%% ytkb:def %%

## 要点

%% ytkb:video:5C_HPTJg5ek %%
### 来自 [[2021-10-12-rust-in-100-seconds]]
- Rust 适合构建对性能要求极高的系统，如游戏引擎、数据库、操作系统，也是编译到 WebAssembly 的优秀选择。（[00:00](https://youtu.be/5C_HPTJg5ek?t=0)）
- Rust 最初是 Graydon Hoare 于 2007 年发起的个人 side project，因 rust 真菌而得名。（[00:00](https://youtu.be/5C_HPTJg5ek?t=0)）
- Rust 于 2009 年获得 Mozilla 的官方赞助支持。（[00:00](https://youtu.be/5C_HPTJg5ek?t=0)）
- 自 2016 年起，Rust 在开发者调查中连续多年被评为最受喜爱的编程语言，其粉丝群体自称 Rustaceans。（[00:00](https://youtu.be/5C_HPTJg5ek?t=0)）
- 新建的 Rust 项目中，程序的入口是 main.rs 文件里的 main 函数。（[00:00](https://youtu.be/5C_HPTJg5ek?t=0)）

# Capability Extension Tools

%% ytkb:def %%
agent 工具的一大类，用于弥补 AI 模型本身能力短板，例如计算器、时区或单位换算器、翻译服务和代码解释器。
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- Agent 工具的第二大类是 capability extension tools，用于弥补模型自身能力短板，例如计算器（因为 AI 模型常常不擅长复杂数学运算）、时区或单位转换器、翻译服务，以及代码解释器（code interpreter）。（[36:03](https://youtu.be/JV3pL1_mn2M?t=2163)）

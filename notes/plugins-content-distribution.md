# Plugins (Content Distribution for Skills)

%% ytkb:def %%
Skill 是内容的编写格式，Plugin 则是内容的分发方式，用于把多个 Skill 或 Skill 与连接器打包共享给团队使用。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-coding-agents]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:KgiwIEBeOHw %%
### 来自 [[2026-06-16-什么是循环工程loop-engineering-coding-agent-子agent-mcp协议]]
- 若要把一个 Skill 共享给多个代码仓库使用，或把好几个相关 Skill 打包到一起，就可以将其封装成一个 Plugin，这一规则在 Codex 和 Claude Code 中都是通用的。（[09:03](https://youtu.be/KgiwIEBeOHw?t=543)）
- Plugin 的作用是把连接器和 Skill 打包到一起，团队成员只需安装一次就能用上整套配置，不用再靠记忆一步步重新搭建。（[09:03](https://youtu.be/KgiwIEBeOHw?t=543)）

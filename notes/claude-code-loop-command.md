# Claude Code /loop Command

%% ytkb:def %%
/loop 是 Claude Code 中的一个指令，用于让某个提示词或命令按照固定间隔重复运行。
%% ytkb:end %%

%% ytkb:video:KgiwIEBeOHw %%
### 来自 [[2026-06-16-什么是循环工程loop-engineering-coding-agent-子agent-mcp协议]]
- 用 /loop 指令可以让一个提示词或命令在 Claude Code 中按照固定间隔重复运行，也可以设置定时任务按自定义周期执行。（[03:01](https://youtu.be/KgiwIEBeOHw?t=181)）

# CSS Box Model

%% ytkb:def %%
CSS 中描述元素几何结构的模型，由内到外依次是 content box、padding box、border、margin box 四层。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[frontend-css-styling]] · [[frontend]]
%% ytkb:end %%

## 要点

%% ytkb:video:AMerB8XjfZ0 %%
### 来自 [[2026-06-30-top-15-frontend-interview-questions-for-2026-wa-se]]
- CSS box model 由内到外依次是 content box、padding box、border、margin box 四个层级。（[21:06](https://youtu.be/AMerB8XjfZ0?t=1266)）
- CSS box model 指网页中每一个元素本质上都是一个盒子（矩形），网页就是嵌套盒子的集合，即便视觉上呈现为圆形的元素在布局层面依然是矩形盒子。（[18:04](https://youtu.be/AMerB8XjfZ0?t=1084)）

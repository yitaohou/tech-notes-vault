# Anonymous ID De-anonymization

%% ytkb:def %%
只要在任何一次对话中出现过真实信息（如公司邮箱、真实姓名），挂在匿名 ID 下的整份长期使用档案就会与真人对应上，从匿名变为实名。
%% ytkb:end %%

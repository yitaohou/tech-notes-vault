# AI 硬编码宽度破坏响应式设计

%% ytkb:def %%
AI coding agent 倾向于给元素直接写死固定像素宽度（如 width: 300px），这种做法会破坏页面的响应式设计效果。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[frontend-ai-coding-assistants]] · [[frontend]]
%% ytkb:end %%

## 要点

%% ytkb:video:AMerB8XjfZ0 %%
### 来自 [[2026-06-30-top-15-frontend-interview-questions-for-2026-wa-se]]
- AI coding model 经常直接给元素硬编码固定宽度（如 300px），这会完全破坏响应式设计，导致页面在桌面端看起来正常，但在移动端显示效果很差。（[21:06](https://youtu.be/AMerB8XjfZ0?t=1266)）

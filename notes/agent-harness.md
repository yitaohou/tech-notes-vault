# Agent Harness

%% ytkb:def %%
harness 指围绕一组同质化 agent 副本搭建的协调机制，例如测试集或任务列表，用于确保任务被实际完成并分配给合适的 agent。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-agent-architecture]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:Mi5wOpAgixw %%
### 来自 [[2026-02-22-multi-agent-systems-explained-in-17-minutes]]
- harness 可以是一组测试用来确认任务确实完成，也可以是一个任务列表，让各 agent 自行认领并勾选已完成的任务。（[09:02](https://youtu.be/Mi5wOpAgixw?t=542)）
- 构建一个有效的 multi-agent harness 并非易事，其具体设计（测试、共享上下文、任务列表等）高度依赖具体使用场景。（[15:06](https://youtu.be/Mi5wOpAgixw?t=906)）

# System Prompt vs User Prompt

%% ytkb:def %%
现代模型区分系统提示词（system prompt）与用户提示词（user prompt）两类输入。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-prompt-engineering]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- system prompt 包含任务描述、模型应扮演的角色、目标与约束，通常由应用开发者预先设定；user prompt 则包含用户的具体任务或查询，两者会通过特定模板组合后一起输入模型。（[24:02](https://youtu.be/JV3pL1_mn2M?t=1442)）

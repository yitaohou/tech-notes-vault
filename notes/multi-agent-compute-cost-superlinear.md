# Multi-Agent Compute Cost Superlinear Growth

%% ytkb:def %%
multi-agent 系统的算力成本随 agent 数量增加而超线性增长的现象，因为除了各 agent 自身消耗算力外，还需要额外算力支持 agent 间的相互沟通。
%% ytkb:end %%

## 要点

%% ytkb:video:Mi5wOpAgixw %%
### 来自 [[2026-02-22-multi-agent-systems-explained-in-17-minutes]]
- 5 个 agent 组成的 multi-agent 系统算力成本会超过单 agent 系统的 5 倍，因为除了每个 agent 本身消耗的算力外，还需要额外算力让所有 agent 之间相互沟通协调。（[06:02](https://youtu.be/Mi5wOpAgixw?t=362)）

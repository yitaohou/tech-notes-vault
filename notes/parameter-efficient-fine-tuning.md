# Parameter Efficient Fine-tuning (PEFT)

%% ytkb:def %%
PEFT 是一类通过在模型策略性位置插入少量额外参数、用较少可训练参数实现强微调效果的技术。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-fine-tuning]] · [[ai]]
%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 可训练参数越多，内存占用越高，这正是 parameter efficient fine-tuning（PEFT）的核心动机：通过减少可训练参数数量来降低微调的内存需求。（[45:04](https://youtu.be/JV3pL1_mn2M?t=2704)）

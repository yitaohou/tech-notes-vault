# Rich Context References

%% ytkb:def %%
相较于传统的简单 Markdown 规范文档，向模型提供更丰富格式的参考资料（如 HTML UI 原型、完整测试套件）来指导其完成复杂任务的方法。
%% ytkb:end %%

## 要点

%% ytkb:video:Lle_EJljIoo %%
### 来自 [[2026-07-26-删掉80提示词后claude-5反而变强了anthropic官方的做减法哲学]]
- 新模型能够直接处理 HTML 格式的 UI 原型作为参考资料，比用几百字描述界面长什么样效果更好。（[06:01](https://youtu.be/Lle_EJljIoo?t=361)）
- 可以把一个完整的测试套件直接交给模型，让它照着测试用例去实现功能，而不只是给一份文字规范。（[06:01](https://youtu.be/Lle_EJljIoo?t=361)）

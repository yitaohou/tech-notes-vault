# Text-to-SQL RAG

%% ytkb:def %%
RAG 应用于表格数据的方式，通过将自然语言问题转换为 SQL 查询，在数据库上执行后基于结果生成回答。
%% ytkb:end %%

%% ytkb:topic %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- RAG 也可以处理 tabular data，做法是把用户问题转换成 SQL 查询在数据库上执行，再基于查询结果生成回答，这种方式称为 text-to-SQL。（[36:03](https://youtu.be/JV3pL1_mn2M?t=2163)）

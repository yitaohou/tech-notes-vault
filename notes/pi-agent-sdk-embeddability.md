# Pi Agent SDK Embeddability

%% ytkb:def %%
Pi Agent 官方文档提供 SDK、RPC、JSON Event 等多种调用方式，使其不仅能作为终端编程工具使用，还能被嵌入到自己的项目代码中调用。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[ai-coding-agents]] · [[ai]]

## 要点

%% ytkb:video:j0Z5cngKDeo %%
### 来自 [[2026-07-27-我为什么对-pi-agent-产生了兴趣]]
- 真正吸引作者深入研究 Pi Agent 的原因，是发现其文档介绍了 SDK，而 Codex、Claude Code 的文档中完全没有 SDK 相关介绍。（[00:00](https://youtu.be/j0Z5cngKDeo?t=0)）
- 以 Node.js 项目为例，开发者可以直接引入 Pi Agent 的 SDK，在自己的程序代码里创建 Agent Session，而不必通过终端交互使用。（[00:00](https://youtu.be/j0Z5cngKDeo?t=0)）

# REST Noun-Based URL Design

%% ytkb:def %%
REST 资源建模的核心原则：URL 应使用名词（如 products、orders）而非动词（如 get products）来表示业务领域中的资源。
%% ytkb:end %%

%% ytkb:topic %%
所属: [[backend-api-design]] · [[backend]]
%% ytkb:end %%

## 要点

%% ytkb:video:oYxTTirKY8M %%
### 来自 [[2026-05-26-system-design-explained-apis-databases-caching-cdn]]
- 在 RESTful API 设计中，业务领域概念（如 product、order、review）应转换为名词形式的资源路径，而不是像 get products 这样的动词式端点。（[63:13](https://youtu.be/oYxTTirKY8M?t=3793)）

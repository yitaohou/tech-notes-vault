# Prompt Depreciation Over Model Versions

%% ytkb:def %%
提示词的有效性具有时效性：为解决当前模型缺陷而添加的规则，随着模型不断迭代升级，很可能在新一代模型上已不再需要，即提示词会随时间折旧。
%% ytkb:end %%

## 要点

%% ytkb:video:Z-4AsgTYv2c %%
### 来自 [[2026-09-02-claude-code-之父建議每六個月刪光你的-claudemd]]
- 一条 Prompt 曾经有效只能证明它在当时解决过问题，并不代表它永久有效，因为模型会不断更新、变得越来越强大。（[12:47](https://youtu.be/Z-4AsgTYv2c?t=767)）

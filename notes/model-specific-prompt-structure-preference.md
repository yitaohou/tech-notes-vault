# Model-Specific Prompt Structure Preference

%% ytkb:def %%

%% ytkb:end %%

## 要点

%% ytkb:video:JV3pL1_mn2M %%
### 来自 [[2025-04-01-ai-engineering-in-76-minutes-complete-coursespeedr]]
- 不同模型偏好的 prompt 结构不同，例如 GPT-4 通常在任务描述放在提示词开头时表现更好，而 Llama 3 则在任务描述放在结尾时表现更好。（[24:02](https://youtu.be/JV3pL1_mn2M?t=1442)）

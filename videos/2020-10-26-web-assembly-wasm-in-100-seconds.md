# Web Assembly (WASM) in 100 Seconds

摘要: [[2020-10-26-web-assembly-wasm-in-100-seconds-summary|完整摘要]]

## 知识点

- [[assemblyscript]] — AssemblyScript 是入门 WebAssembly 开发的最佳方式之一，其语法类似 TypeScript，但会编译为 WebAssembly。（[00:00](https://youtu.be/cbB3QEwWMlA?t=0)）
- [[emscripten]] — Emscripten 是最流行的 WebAssembly 构建工具之一，可以将 C 或 C++ 程序编译为 WebAssembly。（[00:00](https://youtu.be/cbB3QEwWMlA?t=0)）
- [[wasm-binary-format]] — AssemblyScript 代码编译后会生成一个以 .wasm 为扩展名的二进制文件。（[00:00](https://youtu.be/cbB3QEwWMlA?t=0)）
- [[wasm-static-typing]] — 与动态解释型的 JavaScript 不同，WebAssembly 是静态编译语言，具有严格的类型保证，例如 AssemblyScript 代码中不能使用 any 类型。（[00:00](https://youtu.be/cbB3QEwWMlA?t=0)）
- [[webassembly]] — WebAssembly 于 2019 年 12 月成为官方 W3C 标准。（[00:00](https://youtu.be/cbB3QEwWMlA?t=0)）
- [[webassembly-instantiatestreaming]] — 在浏览器中运行 wasm 模块时，可以使用 WebAssembly API 的 instantiateStreaming 方法直接 fetch 该二进制文件，并在返回的 promise resolve 后执行相应逻辑。（[00:00](https://youtu.be/cbB3QEwWMlA?t=0)）
